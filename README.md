# Mythic Metals Decorations

Mythic Metals Decorations is an official addon for Mythic Metals.
It focuses on adding various metal-themed decorations and blocks. 

## Features

Since this type of mod relies heavily on textures for new content, it is very slowly maintained. 
New features only happen when I can find time or people to make new things for it.
Some of the current features in the mod are:

- Chains for most metals.
- Chests with various sizes.
- Crowns for most armor sets.
- Hydrargym, a new metal which uses the legacy Quicksilver colors
